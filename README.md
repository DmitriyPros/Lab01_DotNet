Главные выводы:

1. C# — строго типизированный язык. Тип переменной задаётся явно (int x = 5;), либо выводится компилятором (var y = 5;), но остаётся фиксированным на этапе компиляции.
2. .NET — это бесплатная кроссплатформенная платформа от Microsoft для создания различных приложений.
3. dotnet run — самый быстрый способ запустить программу. Команда автоматически выполняет сборку и запускает приложение.
4. Класс Console — базовый инструмент консольного ввода/вывода: Console.WriteLine, Console.Write, Console.ReadLine.

Ответы на вопросы:

1. Console.Write() - Вывести текст без перехода на новую строку.
Console.WriteLine() - Вывести текст с переходом на новую строку.
2. Компилятор выдаст ошибку компиляции, т.к. int - целые числа, а 3.14 является дробью.
3. Оба операнда — целые числа (int), поэтому оператор / выполняет целочисленное деление: дробная часть результата отбрасывается. Чтобы получить дробный результат, нужно, чтобы хотя бы один операнд был типом с плавающей точкой, либо добавить double.
4. var — это не тип, а ключевое слово, позволяющее компилятору вывести тип переменной по правой части выражения на этапе компиляции. После вывода тип фиксируется и больше не может измениться.
